# What happens when you type https://www.google.com in your browser and press Enter?

This repository contains the documentation and link for the classic system engineering and networking project at Holberton School.

## Description
An in-depth technical walkthrough explaining the journey of an HTTP request across the entire web stack, covering DNS, TCP/IP, Firewalls, TLS/SSL, Load Balancers, Web Servers, Application Servers, and Databases.

## File Structure
- `0-blog_post`: Contains the link to the published blog post on Medium/LinkedIn.
